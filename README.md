# 清末立宪存续模拟器 · 对话式历史演化

**实时AI驱动的历史模拟 · DeepSeek R1 · 对话式交互**

## 🌐 在线访问

部署到Vercel后，可以获得稳定的公开访问链接。

## 🎯 核心功能

### 1. 对话式历史演化
- **类似Character.AI**的对话界面
- 每个历史人物都由DeepSeek R1独立驱动
- 实时生成决策，展现真实的政治博弈

### 2. 用户角色扮演
- 选择任意历史人物
- 插入你的决策
- 观察AI角色如何反应

### 3. 实时指标监控
- 中央合法性、宪政规范、政变风险等8个指标
- 每个决策都会影响指标变化
- 可视化进度条显示

### 4. 导出时间轴
- 一键导出完整的历史演变JSON
- 包含所有决策、指标变化
- 可用于进一步分析或分享

## 🚀 本地运行

### 1. 配置API Key

复制 `.env.local.example` 为 `.env.local`：

```bash
cp .env.local.example .env.local
```

编辑 `.env.local`，填入你的DeepSeek API Key：

```env
DEEPSEEK_API_KEY=sk-your-actual-api-key-here
```

获取API Key: https://platform.deepseek.com/

### 2. 安装依赖

```bash
cd web
npm install
```

### 3. 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:3000

## 🎮 使用指南

### 自动模拟模式

1. 点击 **"▶️ 推进一回合"**
2. AI会自动选择2-3个历史人物做决策
3. 每个人物基于当前局势和自己的政治目标独立决策
4. 决策会影响8个关键指标
5. 历史对话会实时显示在中间栏

### 用户扮演模式

1. 点击 **"🎭 扮演角色"**
2. 从下拉菜单选择你要扮演的人物
3. 在文本框描述你的行动（例如："我联合立宪派，提议召开国会特别会议"）
4. 点击 **"🚀 执行决策"**
5. AI角色会自动对你的决策做出反应

### 导出分享

点击 **"📥 导出时间轴"**，会下载一个JSON文件，包含：
- 所有回合的决策记录
- 每回合的指标状态
- 时间跨度和最终状态

## 🧠 AI驱动逻辑

### Prompt设计

每个AI角色决策时，会接收到：
- **角色身份**：政治目标、制度偏好、盟友对手、红线
- **当前局势**：8个关键指标的数值
- **最近事件**：最近5个回合的历史
- **触发事件**：如果有用户决策，会特别提示

AI会返回结构化决策：
```json
{
  "action": "具体行动（一句话）",
  "reasoning": "内心想法",
  "targets": ["受影响的人物"],
  "type": "constitutional_reform / power_struggle / ...",
  "publicity": "public / private / secret",
  "tone": "aggressive / cautious / conciliatory / neutral"
}
```

### 指标更新

每个决策会触发指标变化：
- **宪政改革** → 宪政规范↑ 议会合法性↑ 政变风险↑
- **权力斗争** → 袁世凯权力↑ 政变风险↑↑ 中央合法性↓
- **军事行动** → 政变风险↑↑ 北洋凝聚力↓
- **谈判** → 中央合法性↑ 政变风险↓
- **财政政策** → 中央合法性↑
